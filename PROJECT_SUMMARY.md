# Fire Forecasting: project summary

## What this repository is now

A **dashboard prototype**: a Next.js 14 (App Router) front end with MUI, Leaflet and
ApexCharts that shows **sample** wildfire-risk forecasts for the Tri-County area
(Santa Barbara, Ventura and Los Angeles counties).

- `/`: KPI cards, a Leaflet forecast map, a 72 h risk chart and a site table.
- `/map`: the same map, full width.
- `/settings`: display and data preferences, saved in the browser.
- `/ml-history`: a model-run history table filled with clearly labelled example data.

The data behind the UI is `frontend/lib/sample-forecast.json`, generated by
`scripts/build_sample_data.py` from the committed `data/trihourly_weather.csv`
(see [docs/DATASET.md](docs/DATASET.md)). The weather rows are real values from that CSV;
the eight monitoring sites and their risk values are fictional samples. Nothing in the
repository trains or serves a model.

## History

The first versions of this project (up to commit `300d8da`) also contained:

- a Python pipeline (FIRMS, RAWS and FRAP loaders, feature engineering, FIRMS-proximity
  labelling, chronological splits, ANN/LSTM and baseline models);
- a FastAPI backend serving metrics, curves, geo layers and retraining routes.

Commit `bd4c682` removed the backend, the pipeline and their configuration to restart the
project as a front end. That code is still in the git history:
[tree at 300d8da](https://github.com/TRUPALIX9/fire-forecasting/tree/300d8da).
